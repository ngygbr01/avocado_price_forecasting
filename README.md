# Avocado Price Forecasting

This repository contains a university assignment for the **University of Szeged (SZTE)**. The project analyzes weekly U.S. avocado prices from January 2015 to March 2018. It compares three methods for forecasting conventional avocado prices, measures the price premium for organic avocados, and examines how the two prices move together across eight regions.

## Research Questions

1. How accurately can we forecast next week's conventional avocado price using trend, seasonality, and regional differences? During which weeks are the forecast errors largest?
2. How much more do organic avocados cost than conventional avocados in the same region and week? How does this price premium vary across regions and over time?
3. How closely do conventional and organic avocado prices move together? Are both types expensive during similar periods, and how often do their prices change in the same direction from one week to the next?

---

## Dataset

The analysis uses Justin Kiggins's [Avocado Prices dataset on Kaggle](https://www.kaggle.com/datasets/neuromusic/avocado-prices), compiled from Hass Avocado Board retail data.
