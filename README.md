# Avocado Price Forecasting

This repository contains my university assignment project for the **University of Szeged (SZTE)**. The main objective of this project is to analyze historical avocado prices and sales volumes, and to build predictive models based on the dataset.

## Research Question
This analysis will answer the following research question:
* How predictable is the price of avocados based on trend, seasonality, and regional differences, and during which periods does the forecast deteriorate noticeably?
