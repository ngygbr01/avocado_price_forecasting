# Avocado Price Forecasting

This repository contains my university assignment project for the **University of Szeged (SZTE)**. The main objective of this project is to analyze historical avocado prices and sales volumes, and to build predictive models based on the dataset.

## Research Questions
In this analysis, I aim to answer the following key questions:
* *How do avocado prices fluctuate across different regions and seasons?*
* *Is there a significant price difference between conventional and organic avocados?*
* *Which machine learning model predicts future avocado prices most accurately?*
